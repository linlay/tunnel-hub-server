# T6：跨仓联调、渲染资源同步、发布交接与清理

状态：待执行。责任：集成负责人协调四仓。前置：T1–T5 的模块验收；HTML 最小浏览器门槛须已提前执行。最终合同见 [01](01-solution.md)，任务顺序见 [00](00-overview.md)。

## 1. 边界

本任务将功能串联并验证，不新增功能平台、自动化运维系统或另一份媒体处理逻辑。正式部署需当次授权；未经授权做到可审查、可发布的匹配产物与记录，不自行提交、推送或部署。

不能因文档已落档、构建成功或单元测试通过，就把整项功能标记完成。

## 2. 联调样例

使用合成/脱敏会话和本次创建的测试文件，覆盖：

| 样例 | 必须包含 |
| --- | --- |
| 基础内容 | 文字、代码、引用、Planning、公式、Mermaid/ECharts、等待/工具输出 |
| 媒体来源 | 成功/失败图片生成、仅附件 query、人类 steer、Markdown 媒体、已发布普通文件 |
| HTML | 内联脚本/CSS、同目录媒体、`@chat/`、srcset/poster、HTTPS 静态依赖、明确不支持的动态/本地非媒体依赖 |
| 部分失败 | 已删除、无权限、变更、超资源额度、冻结超时、元数据超额度、损坏/不支持编码 |
| 分享策略 | 普通限时、永久、一次性、撤销、到期、错误资源 ID |
| 历史兼容 | 无新增字段的旧 V1、已冻结 HTML 的旧分享、未冻结媒体的旧分享、旧下载 HTML 与历史 hash |

不消费用户真实一次性链接，不将真实 token、会话全文或本地绝对路径写入测试记录。

## 3. 端到端验收矩阵

| 场景 | 预期结果 |
| --- | --- |
| 主会话 → 应用内预览 → 公开分享 → 下载 HTML | 共同布局/状态一致，无隐式主应用依赖；下载 HTML 的未打包媒体明确降级 |
| 创建全部成功 | 最终目录、上传文件、size/hash 与引用一致；静态快照不随原 Chat 后续变化 |
| 创建部分成功 | 链接可用；创建结果逐项列名/原因；正文及对应节点/HTML媒体处有占位 |
| 正文/必要元数据无法放入额度 | 创建失败；无假链接、悬空附件或泄漏暂存 |
| 原生媒体 GET/HEAD/Range | 正确 200/206/416、MIME、长度；可跳播，HEAD 不带正文且不认领 |
| 一次性首次访问及续读 | 一次合法认领；同浏览器有效期内页面/附件可读，其他浏览器拒绝；附件直达不认领 |
| 到期或撤销 | 所有后续页面、文件、Range、embed 请求均拒绝；已交付字节不声称可追回 |
| HTML 独立页与浮层 | 走同一 Viewer；直接 preview 重定向；JS 与约定媒体可用 |
| HTML 隔离 | 父页面脚本策略未放宽；opaque guest 无父级身份能力，无任意资源桥 |
| 预览关闭/切换/快速导航 | 无迟到结果、重复交付、残留 worker/iframe/端口或任务级缓存 |
| 外部 HTTPS 依赖失败 | HTML 可能功能受限，父页面仍可读；不偷偷代理、抓取或回填 |
| 历史分享及下载文件 | 当前模板可修旧分享展示；缺失旧媒体需重建分享；旧 hash 文件继续可访问 |

HTML 隔离必须记录 Chrome、Safari、Firefox 实际版本和结果；至少覆盖内联/HTTPS脚本、guest Blob 媒体、一次性 Cookie、SRI/CORS、写入文档后 CSP、伪造/重放消息及导航竞态。网络面板确认 bootstrap 资产不依赖分享 Cookie，guest 没有因媒体加载要求放宽 Cookie。

“浏览器支持原生媒体”不等于所有视频/音频编码都支持：包含一份可播样例和一份不支持样例，后者必须给下载回退。不能以服务端 200 代替播放验证。

## 4. 检查和同步命令

以下是实施阶段检查清单，不是本次文档落档已经执行的结果。各仓先遵守本仓 README/AGENTS；命令缺依赖时报告，不擅自修改环境或跳过后写通过。

### Platform

运行 T1 相关 Go 测试、导出与读取集成测试及仓库要求的构建。检查纯投影没有文件 I/O、资源只发现一次、HTTP/工具快照出口一致；不重开既有额度方案。

### Desktop

执行 T2 的相关测试、架构/契约/i18n 检查及本仓完整测试要求。确认契约源与生成结果一致；检查 macOS/Windows 路径及构建脚本带来的文件变动。不得为了联调修改 service-owned 配置或将真实凭据写入产物。

### WebClient 与渲染资产

先通过类型、边界、Desktop 契约、i18n、相关单元测试和主 WebClient 构建，再从同一次源码状态显式发布渲染产物：

```sh
npm run release:conversation-export
npm run check:conversation-export-sync
```

现 release 命令执行构建、同步、检查，会修改 sibling Tunnel 的当前模板、manifest 和新 hash 目录，必须事先记录这些文件状态。检查 bootstrap、runtime、样式、字体及关联资源齐全，hash/SRI匹配，无主应用运行时模块。不得手改压缩产物修功能。

当前 bundle 增加固定 bootstrap 入口不意味着允许任意未知 chunk；沿用现构建约束。所有新文件都由同一次构建和现 manifest 产生，不增加平行发布脚本。

### Tunnel

在同步后的资源上运行相关 handler/shareassets 测试、构建和本仓要求的 `make test-all`、`make verify-neutral`。保持 `GOTOOLCHAIN=local` 与中性 module path；环境路径转换只使用现 `tools/moduleprep`，不能原地替换 go.mod/import。

MySQL 测试使用独立账号和随机库，SQLite 使用临时文件；禁用词名单按既有外部配置提供。不读生产库、不清理历史卷、不输出 DSN/token。未具备条件的检查记录原因和下一步，发布门禁未满足时不能宣称可发布。

## 5. 发布与回滚交接

1. 记录四仓实际 revision、当前 renderer assetSet、模板/manifest 一致性及已验证浏览器版本，不只记录分支名。
2. 第一批：部署兼容旧快照的新 Tunnel + 匹配的新 renderer/bootstrap 资产，复验旧分享与新资源路由。
3. 第二批：交付配套 Platform/Desktop 和主 WebClient，开启新候选与新字段实际创建链路，使用一次性合成会话复验。
4. 保留原冻结时点语义，不批量回填旧快照。旧链接未保存的媒体需要用户重新创建分享；旧下载 HTML 需要重新导出才能使用新 renderer。
5. 保留历史 assetSet；同一 hash 内容不可变。回滚前确认目标版本接受已创建的新合同；不要直接回滚到拒绝新 sourceRef 的旧 Tunnel。
6. 未获正式部署授权时，交付上述完整版本组合、验收结果和可执行发布步骤即可；不得为等待批准而省略构建、同步和检查这些可审查准备工作。

## 6. 架构终审：逐项确认没有过度设计

- [ ] 对已冻结且可由浏览器/前端直接读取的普通附件，新增预览只扩展一个分派入口和对应只读视图，无需改节点合同、冻结、存储、鉴权或同步主链；需要转换、额外 worker/CSP 或新资源准入的格式明确单独评估。
- [ ] 没有新数据库表/版本、ConversationViewModel、Repository、通用插件注册、格式方法集合、资源代理或持续同步任务。
- [ ] HTML bootstrap 只有固定一次交付，没有任意 URL 请求、后续 RPC、认证票据或跨域附件权限。
- [ ] 共享组件不再导入主应用运行时；原主会话操作通过宿主保持。
- [ ] 资源发现只有 Platform 一份；HTML原文只存一份；节点引用不复制完整附件元数据；省略清单是一份事实来源。
- [ ] 新逻辑替换的旧清洗器、回退、布尔状态和死代码已删除，保留项均有真实调用方。
- [ ] 测试覆盖曾经的失败及新边界，没有为增加测试数重复实现业务逻辑。

若其中任一项失败，回到所属任务修正；不能用“以后可能用到”作为保留抽象或双轨逻辑的理由。

## 7. 必做清理审计

在任何临时修改前记录准确可恢复状态：Git 配置/remote/refspec/分支/worktree、环境文件、代理、凭据、hooks、工具配置及待覆盖的生成文件。优先使用进程级参数，不为方便做持久改动。

完成或失败时逐项检查：

1. 各仓 `git status --short`、完整相关 diff 与 `git diff --check`；预先存在的用户修改保持原样。
2. 所有改过的配置逐项比对并恢复；不使用 `git reset --hard`、广泛 `git clean` 或覆盖用户文件来“清理”。
3. 停止本次启动的服务/worker，关闭临时页签和端口，删除本次合成 Cookie/测试分享；验证已停止或已删除。
4. 删除归属明确的临时 Chat、测试媒体、导出样例、暂存文件、临时 SQLite/随机 MySQL 库；归属不明的留存并报告。
5. 必需的新 renderer 资产、模板、manifest 和契约生成文件属于交付物，应保留；历史资产/数据库/卷及用户原文件不是临时产物。
6. 报告剩余文件、未验证项和配置差异。无法完成/验证清理时给出准确路径与修复命令，任务标记未完成，不能只写“后续清理”。
