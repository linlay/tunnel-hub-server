# WebClient：展示与浏览器读取

公开 V1 解析只验证结构，不执行新建分享额度，也不分配整份 TextEncoder 数据来测量大小。

浏览器从 Platform 响应头读取额度，在现有资源请求模块内按实际 chunk 有界读取；模板同一读取器使用原 256 KiB 上限。读取器负责大小，组装器只验证模板结构。

HTML 继续通过 Blob parts 嵌入 Platform 已安全序列化的 JSON；删除固定 Snapshot/HTML 上限、组装时的模板大小复查和无调用方错误函数。上一版逐字节转义器、空间推导及整份输出缓冲区完全撤除。

验证：5 个既有相关测试套件共 144 项通过；类型、边界、Desktop 契约、i18n 通过；渲染发布及同步检查通过。22 MiB 快照的 Blob HTML 组装通过。
